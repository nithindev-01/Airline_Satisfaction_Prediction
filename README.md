# Airline Passenger Satisfaction — End-to-End Classification

End-to-end supervised binary classification with **Optuna + MLflow + Streamlit**.

## Models used

Exactly five classifiers:
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. XGBoost
5. CatBoost

SVC is removed. ExtraTrees and HistGradientBoosting are not included.

## 1. Dataset setup

Use the Kaggle Airline Passenger Satisfaction dataset. Put the two CSV files here:

```text
data/train.csv
data/test.csv
```

Both files must contain the target column `satisfaction`. Supported target labels:
- `satisfied`
- `neutral or dissatisfied`

Numeric labels `1` and `0` are also supported. The project maps satisfied to 1.

The dataset is not included in this ZIP. Download it separately from Kaggle.

## 2. Create environment (Windows PowerShell)

Use Python 3.11 for a compatible package environment:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 3. Run training, Optuna tuning and testing

The default is **20 Optuna trials per model**, five models, or 100 total trials.

```powershell
python train.py
```

The script:
1. Loads train and test CSV files.
2. Builds preprocessing inside a Scikit-learn Pipeline.
3. Runs a baseline CV comparison.
4. Tunes each model with Optuna's TPE sampler.
5. Uses 3-fold StratifiedKFold and ROC-AUC as the optimization metric.
6. Logs trial parameters and CV scores to MLflow.
7. Compares the five best CV scores.
8. Selects the winner using training CV only.
9. Fits only the winner on all training data.
10. Evaluates the winner once on the untouched test data.
11. Saves the final pipeline and Streamlit input schema.

For a quick smoke test (only two models and two trials each):

```powershell
python train.py --n-trials 2 --cv-folds 2 --models logistic_regression decision_tree
```

Optional arguments:

```powershell
python train.py --n-trials 20 --cv-folds 3
python train.py --n-trials 20 --models logistic_regression random_forest xgboost
python train.py --tracking-uri sqlite:///mlflow.db
```

## 4. View MLflow experiments

In a separate terminal, activate the same virtual environment and run:

```powershell
mlflow ui --backend-store-uri sqlite:///mlflow.db
```

Open:

http://127.0.0.1:5000

MLflow stores the experiment, model-level tuning runs, individual Optuna trials,
best parameters, baseline results, final test metrics, plots and logged model.

## 5. Run Streamlit locally

After training has completed and the artifacts folder contains the model:

```powershell
streamlit run app.py
```

Streamlit opens the application in your browser, usually at:

http://localhost:8501

Enter passenger details and click **Predict passenger satisfaction**.

## 6. Deploy to Streamlit Community Cloud

### Prepare GitHub repository

1. Create a new GitHub repository.
2. Upload `app.py`, `train.py`, `requirements.txt`, `README.md` and the `artifacts/` folder generated by training.
3. Do not upload `.venv/`, `mlruns/`, `mlflow.db`, or the original CSV files.
4. Ensure `artifacts/best_model.joblib`, `artifacts/input_schema.json` and `artifacts/winner.json` are committed. These are required for inference.

Suggested repository layout for deployment:

```text
repository/
├── app.py
├── train.py
├── requirements.txt
├── README.md
└── artifacts/
    ├── best_model.joblib
    ├── input_schema.json
    └── winner.json
```

### Publish app

1. Open https://share.streamlit.io/
2. Sign in using GitHub.
3. Select **Create app**.
4. Choose your repository and branch.
5. Set the main file path to `app.py`.
6. Select **Deploy**.

Streamlit Cloud installs dependencies from `requirements.txt` and runs `app.py`.

**Important:** Train the model locally before deployment and commit the generated model artifacts. Streamlit Cloud runs the prediction application; it does not automatically run the Optuna training process. Keep the MLflow database and experiment artifacts locally or configure a remote MLflow tracking server if you want hosted experiment tracking.

## 7. Important ML design choices

- Imputation, scaling and One-Hot Encoding are inside the pipeline, so they are fitted within each CV training fold.
- Optuna uses 20 trials per model by default.
- 5 models × 20 trials = 100 optimization trials.
- The winner is selected by training cross-validation ROC-AUC, never by test-set performance.
- The test set is used only for the final evaluation of the selected model.
- The saved Joblib pipeline includes preprocessing and the winning classifier.

Only load model files from sources you trust.
